How it works

From a file to a running Claude Code

  1. 1

    Get the file

    Copy or download it from the customizer, or fetch a template as it is:

    curl -fsSL /p/code-reviewer.cpb -o reviewer.cpb
  2. 2

    Read it, then check it

    A recipe is plain statements. --dry-run shows every change and command before anything is written.

    cpb APPLY reviewer.cpb TO review --dry-run
  3. 3

    Apply it

    Applying twice changes nothing. The playbook gets its own command; run it like any other.

    cpb APPLY reviewer.cpb TO review

Secrets are references

A GitHub token appears as FROM 'keychain:github-mcp', resolved at launch by your secret helper. The customizer refuses anything that looks like a credential, and so does cpb.

A sandbox is a creation flag

SANDBOX is set when the playbook is created, so a recipe cannot carry it. In recipe form the customizer puts it on the cpb CREATE PLAYBOOK line; in file form it is in the file.

Same code, tested

The files in /p/ and every option combination are applied by a real cpb in CI. If a template stops working, the build fails, not your afternoon.
