claude-playbooks · isolated Claude Code instances

Run more than one Claude Code, isolated as far as you choose.

cpb gives every project, account or model backend its own CLAUDE_CONFIG_DIR: its own memory, hooks, skills, plugins and MCP servers, and, when you want it, its own environment, login and microVM. Each one is described in a file you can apply anywhere.

Four layers

Isolation, as far as you choose

Every playbook has its own config home. Go further per playbook: its own environment, its own login, its own process. The dots show which of the five above use each layer.

Config home

Its own CLAUDE.md, settings, hooks, memory, history, sessions, plugins, MCP servers and skills. Your ~/.claude never moves.

Its own variables, set or blocked at launch: another model backend, another token, another proxy. Your shell stays as it is.

Recipes

Describe it once. Apply it anywhere.

A .cpb file is a recipe. APPLY checks all of it before it writes anything, --dry-run shows each change, and applying it twice changes nothing. SHOW CREATE ALL exports a whole machine as statements.

The tour

Every command, with the output it really printed

The tour runs each snippet on a throwaway home against a real build, and CI re-checks them on every change.

Try things safely →A scratch playbook, used and dropped. Your ~/.claude is never touched. Routing & models →Env sets, BLOCK VAR and a custom /model list. Sandbox →Let an agent loose without letting it near your machine. The grammar →APPLY --dry-run, SHOW CREATE and recipe files. MCP & secrets →Credentials by reference, never by value. Sessions, SQL & the TUI →Everything that is running, as tables, and cpb tui.

Testing

How it is tested

Every change is tested the same way, on the exact commit a release tags.

20 examplesapplied in CI on every change: dry run, apply, re-apply (a no-op), then each README's own checks.
upgrade-testedThe previous release's binary applies its own examples; this build takes over the same state and must read it identically.
arena regressionA full gentar run on the exact commit each release is tagged from.

Get it

Install

Linux and macOS, amd64 and arm64 (no native Windows; WSL works). It installs claude-playbook and the shorter cpb.

$ curl -fsSL https://raw.githubusercontent.com/ramazanpolat/claude-playbooks/main/install.sh | sh
