Runtimes

Isolated by default. Connected on purpose.

Run each agent where it belongs: on your machine, in a microVM, in an OpenShell container, on another machine, or in a throwaway folder. Nothing is shared unless you share it. Hover an agent to see what it reaches; where two agents reach the same thing, they can meet.

cpb does not pass messages between agents. What it does is decide what each one can reach: a model backend, an MCP server, a folder. The places two agents have in common are the places they can meet, and nowhere else. The sandbox details are in the sandbox guide; OpenShell needs Linux with Docker.

Recipes

Describe it once. Apply it anywhere.

A .cpb file is a recipe. APPLY checks all of it before it writes anything, --dry-run shows each change, and applying it twice changes nothing. SHOW CREATE ALL exports a whole machine as statements.

Get it

Install

Linux and macOS, amd64 and arm64 (no native Windows; WSL works). It installs claude-playbook and the shorter cpb.

$ curl -fsSL https://raw.githubusercontent.com/ramazanpolat/claude-playbooks/main/install.sh | sh
